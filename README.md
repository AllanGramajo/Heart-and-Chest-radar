# Heart and Chest Radar

Interactive classroom website by Allan Gramajo and Alan Acosta.

This repository is being populated with the website source and an automated build that verifies and embeds a public MobiVital recording before publication. Simulations are labeled separately from published results and recorded measurements.

## Publication

After the deployment files have been uploaded, enable **Settings → Pages → Source → GitHub Actions**. The deployment workflow must complete successfully before the website is available.

The planned project site is https://allangramajo.github.io/Heart-and-Chest-radar/ . This address is not a confirmation of a completed deployment.

No patient data, credentials, or access tokens should be added to this repository.
