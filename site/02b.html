Why this comparison fails at 20 samples/s
|Δφ| < π → |Δd| < λ/4

The same synthetic target is sampled independently at 20 and 120 Hz. A smooth 20 mm shift over 0.5 s exceeds the nearest-neighbor unwrapping limit at the slower rate. I = cos(φ), Q = sin(φ), atan2 and phase accumulation produce both reconstructions. Initial position is anchored to the known input; an absolute uncalibrated position is not recovered.

A lost phase turn can leave a constant offset. It need not destroy the breathing amplitude. Higher sample rate resolves this particular idealized trajectory, not every motion artifact in a person.

Monte Carlo protocol and model checks

Six cells per side; baseline 1; additive Gaussian noise; within-side correlation 0.20; sides independent; negative cell values clipped to zero. At each severity, 512 training maps per class set a midpoint ratio threshold, then 2,048 held-out maps per class estimate balanced accuracy. A new threshold is fitted at every severity: this is a separability experiment, not one deployable detector.

Crossings are linearly interpolated on a 1% severity grid. At zero noise, any positive reduction separates the ideal classes; the displayed 0–1% interval is grid-limited. The 90% line is not clinical sensitivity, and no patient-derived noise model or confidence interval is claimed.

What is verified

Specified geometry, phase recovery for an ideal target, a sampling failure, and held-out separability under declared noise assumptions.

What is not validated

True lung ventilation, 12 resolvable radar cells, motion robustness in people, disease detection, or improvement to an ECG model.
